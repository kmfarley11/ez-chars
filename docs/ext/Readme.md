# External Documents

This folder contains third-party reference assets that the project is permitted to redistribute. The build publishes approved files beneath the application's configured base path at `docs/ext/...`.

The canonical asset inventory, checksums, provenance, licensing, modification status, and required attribution are maintained in [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).

`local-only/` is reserved for lawfully obtained source-review material that must never be committed, served by the development server, or copied into a production build.
