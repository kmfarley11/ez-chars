# BL-086 Consumer and Coverage Inventory

## Status and Migration Rules

2026-10-12 rollout: owner approved task 2.1. The tables below preserve the pre-gate inventory; the delivered reconciliation at the end records actual destinations and retirements.

2026-10-11: initial source/consumer inventory, before extraction. Destinations below are proposals until the proof gate approves broad migration. No story or fallback is authorized for deletion merely by appearing here. See [verify.md](verify.md) for executable evidence and [tasks.md](tasks.md) for gates.

For each family, move its stories, story wrappers, and nearby tests with its owner, using kebab-case basenames. Component identifiers remain PascalCase. Retained locations are deliberate, not alternative generic component roots.

Dependency direction: application hosts → system compositions → generic UI → neutral types/utilities. Application hosts own storage and browser routing. Story hosts own isolated data and local navigation. Production must not import stories/concepts. Generic UI must not select a system through a helper or reference-catalog fallback.

## Proof Slice and Audit Limits

### Delivered pre-gate source sample

- `src/lib/systems/dnd5e-2014/pages/character-sheet.svelte` now owns the actual markup, projections and edit callbacks; the route remains the storage/history host. Existing system organisms are imported from their old homes until task 3.2, deliberately avoiding simultaneous broad moves.
- `src/lib/systems/dnd5e-2014/editing/sheet-edit-session.ts` consolidates candidate, runtime patch, grid, intent and pin handling for app and section examples. Focused adapters use the same candidate acceptance boundary. New tests live beside it.
- `src/lib/resources/annotation-reference-context.ts` contains only neutral types/context; the former `annotationReference.ts` implementation moved to `src/lib/systems/dnd5e-2014/annotation-reference.ts`. Both note surfaces inject this provider from the 2014 host. The generic provider's absence means external-only handling, never implicit catalog selection.
- `src/lib/systems/dnd5e-2014/pages/character-sheet.stories.ts` provides Saturated through the isolated host; `src/lib/ui/organisms/read-first-detail.stories.ts` provides the schema-light workflow. Both reuse existing UI, with visible guidance and no play functions. Clone/reset/rejection tests are separate from manual UI review.
- The full Page audit exposed missing heading semantics. CollapsiblePanel now wraps its existing button with an h2, protected by its existing nearby contract test. Its header controls, IDs, collapse state and navigation callbacks remain intact.
- No prior story, proof helper or live fallback has been removed in this batch. The proposed retirement table above is still subject to task 2.1 review.

- Pre-gate new examples: one Read-first Detail organism and one canonical Saturated Page. Bryltin and Zindra remain unchanged fixtures and join the Page catalog only after approval.
- App navigation/persistence remain tested through existing black-box Playwright suites; isolated clone/reset/commit through pure Vitest contracts. Catalog render checks are not proof of reset/switching UI behavior.
- Current hidden chain to remove: SmallEditDialog / FieldAnnotationControl → annotationReference → dnd5e2014ResourceCatalog. Generic controls must receive a neutral provider; there is no default 2014 fallback.
- Full source moves, final transitive import scan, `$components` alias cleanup, and test-by-test retirement signoff remain section 3/4 work. This initial inventory does not claim those outcomes.

## Delivered Rollout Reconciliation — 2026-10-12

- Generic families moved to the inventoried `src/lib/ui/atoms`, `molecules` and `organisms` homes with kebab-case filenames and colocated stories/tests. `$components` and the old system helper root have no remaining source consumers. App controls intentionally retain their source locations.
- System components, stories and edit helpers now live under `src/lib/systems/dnd5e-2014`. Generic UI has no direct system imports; neutral utilities/resources do not select the 2014 provider. The injected reference seam resolves the previously identified hidden dependency.
- Former Atoms/Molecules/Organisms stories map to **Design System** only when generic; domain-dependent examples map to **Systems / D&D 2014**. App list/import/export stories map to **Application**. Canonical **Systems / D&D 2014 / Character Sheet** now provides Bryltin, Zindra and Saturated through one keyed, isolated production-backed host.
- GridContentList SaturatedGear became schema-light **Dense**, with Sparse, Empty, NoMatches and AnnotatedLongContent. IconButton has one configurable primitive sandbox. FieldGroupView's existing distinct fixtures remain. Navigation proof remains system-owned because its browser-history harness supplies evidence absent from sandbox-local canonical navigation.
- Dense collection section stories now use the production edit session for saves and projections instead of inert intent callbacks and independent pin reducers. Runtime/source/error and density-threshold fixtures remain system-owned.
- CharacterList consumes new generic `table.svelte`, `table-row.svelte` and `table-cell.svelte` presentation. TableHeader remains live; application-owned columns, mobile cards, action handoff and focus remain in CharacterList. Old domain-coupled Table and text-only TableDataRow were retired.
- Final review adds one Design System / Molecules / Table / Composition sandbox, not separate row/cell fixtures. Existing GridPrimitiveField stories are now labeled Edit-first Fields (Tier 1); the maintainer guide maps runtime, read-first and collection interaction patterns without changing their composition classification. System section titles and local component aliases omit redundant Dnd5e2014 prefixes; qualified domain contracts remain unchanged.
